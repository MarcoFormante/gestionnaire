English:
# Address Book Manager - OPENCLASSROOMS
## Student: Marco Formante

In this exercise, you will build an address book manager that runs in a command-line terminal. When your program is launched, it must offer several options in the console:

- Display the list of contacts: list
- Display the details of a contact: detail
- Add a contact: create [name], [email], [phone number]
- Delete a contact: delete [id]
- Quit the program: quit
- Bonus: you can add a command to display help and another to edit a contact.

Here is an example of how the program should be used once you have built it:

Enter your command (help, list, detail, create, delete, quit): help

-help: displays this help
-list: lists the contacts
-create [name], [email], [phone number]: creates a contact
-delete [id]: deletes a contact
-quit: quits the program
---

### How to test the command-line manager:

1. Download the project folder from the repository.
2. Open a terminal at the root of the project.
3. Run the following command:
  ```bash
  php main.php
  ```
4. Follow the instructions displayed in the console.
